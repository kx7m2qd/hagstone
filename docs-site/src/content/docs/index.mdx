## Scan a project in one command

```sh
npx hagstone scan .
```

Requires Node.js 22 or newer on Linux x64 or macOS arm64. The first run downloads the pinned scanning engines, checks their SHA-256, and caches them. [Installation](/docs/getting-started/installation/) covers the details.
