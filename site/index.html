FAQ

Questions, answered plainly.

Does my source code leave my machine?

No. Every engine runs locally or in your own CI runner. To look up vulnerabilities and package risk, Hagstone sends package names and versions to osv.dev, npm and PyPI, and nothing else. With --offline it sends nothing at all.

Is it really free?

Yes. The scanner is open source under Apache-2.0, with every engine included and no per-user pricing.

Which languages and formats are covered?

Code: JavaScript/TypeScript, Python and Java. Dependencies: the ecosystems OSV-Scanner supports. Infrastructure: Terraform, Kubernetes, Dockerfile, Helm, CloudFormation, ARM and Ansible. Plus container images, SBOMs and licenses.

How do I adopt it on a large codebase?

Run hagstone baseline create and commit the file. From then on you only see new findings, or old ones that got worse.

Can it run in an air-gapped network?

Yes. Download the engines and the vulnerability databases once with hagstone engines install and hagstone offline-db, copy the cache across, and scan with --offline. Nothing is sent anywhere.
